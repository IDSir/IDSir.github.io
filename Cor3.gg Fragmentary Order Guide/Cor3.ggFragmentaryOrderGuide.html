Signal Decode

Count out the number of pulses that you see. Morse is easier to decode.
The number will be a multiple of 4 or 5. You can close and reopen to get a different code.
Once you get to 20 characters, you will have to listen to the code to see which is which.
We’ve seen lengths of 12,15,16,20, 25, 40 and 50 so far.
12, 16, 20 and 40 are Binary. 15, 25 and 50 are Morse.

A multiple of 5 is Morse. A multiple of 4 is Binary.

Otherwise, you simply match the S and L (Short and Long). Split the code into segmented chunks.
Then match the chunks, Short and Long, to the segments you have.
I have edited pictures here to show these chunks.

Binary is the same give or take, with 4 character segments.

System Log Integrity
You need to pick the correct logs from the list, but the help telling you which logs to pick is on the second page!

The second log in this list is missing its /status. So it is a violation.

The sixth one, seen in the image below, has its sector as “289”, which is outside the allowed range.
And the minutes in the time slot are “67”, which is also outside the range.

The help at the top of this window tells you exactly what to look for.

[HH:MM:SS] <TYPE> /Sector=<1-256> /status=<OK|WARN|ERROR>

HH must be 00-23
MM,SS must be 00-59
TYPE must be one of AUTH, TEMP-SYNC, SCAN, ROUTE-CHECK, RADIO-TEST, PING, SYNC
SECTOR must be present, and between 1 and 256.
STATUS must be present, and one of OK, WARN, ERROR

Simply check off this list for the obvious violations, such as completely missing sections, then for finer details like numbers outside ranges and incorrect text.

ACT 3 - Jobs

Currently there are multiple known Markets available that can give Jobs for the player to complete, these are accessible on the Network Map.
Home (Available from start)
D4RK RM7MI (Unlocked early in ACT 3)

Each server has a number of jobs available. All of them other than “File Decryption” involve a server on the Map.
Note: the Access Conditions -

If the Condition is "Acquisition", you will need to have hacked the server to login to it.
If the Condition is “Grant”, you are automatically given access while the Job is active.

If you remove a file / log or IP not requested via a job, the server will trip into maintenance, and cannot be accessed until the red timer on the map expires.

You can refresh the job list (to scan if a job is complete) by clicking the Job button on the market, no need to navigate away and back.

JOB TYPES:


File Decryption -


Upon accepting the task, an encrypted file is added to your downloads folder. Simply double click it and complete the minigame, then back in the market, complete the job.
The file will self delete from the folder.

IP Cleanup -

Connect to the server listed and on the Transit Access tab, click the delete button for the required IPs. Job Done.

IP (adding) -

Connect to the server listed and on the Transit Access tab, click the add button for the required IPs. Job Done.
NOTE: if you open the job info tab in the market, there is a copy button for each IP to save you manually typing each one.

Log Deletion -


Connect to the listed server, and on the Log Tab, find the listed log, and click the delete button. Job done.
NOTE: there can be more than one log with the same name, deleting the wrong file will put the server into maintenance after a short time, so be fast with multiple. It is possible to use F12 to find the actual file, but it is usually the one with the odd (smallest) size, the 3.86mb file in this case.

Log Download -

Connect to the listed server, and on the Log Tab, find the listed log, and click the download button. Job done.


File Elimination -



Connect to the listed server, and on the Files Tab, find the listed file, and click the delete button. Job done.

File Download -

Connect to the listed server, and on the Files Tab, find the listed file, and click the download button. Job done.

File Upload -

Connect to the listed server, and on the Files Tab, click the upload button and navigate to the supplied file, it will be in your downloads folder. (Given when accepting the job.)

Download And Decrypt -

This task is a File Download PLUS Decryption. Connect to the listed server, and on the Files Tab, find the listed file, and click the download button, then open the file in your downloads folder, complete the minigame then job done.
Sometimes you will have a normal Download task, with a padlock icon, this is one of these tasks.

Decoding the drive
Open the MR-7 Media Reader 78X application in your task part, and click on the hard drive to load it. This will then open a new mini-game. The manual for the mini-game is on your desktop in the file “manual.txt”, it’s an extensive document, but the steps do not appear to be unique for everyone can just be followed as per below.

Select FIX and it’ll pop up the mini-game. In this mini-game you have 3 attempts through a 10-timer, however if you fail it’ll just take you back to the beginning, there is no cooldown or timegames fortunately.

There are multiple steps to the mini-game, and each requires you change various settings to go to the next.

2, 1, 6, 5

TOOL = 27
